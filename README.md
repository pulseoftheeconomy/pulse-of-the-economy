## What is this repository?

This is the public source of the Pulse of the Economy blog — the static site served at https://pulseoftheeconomy.netlify.app.

- `index.html` — the homepage (magazine front page, search, dark mode)
- `gold/`, `bitcoin/`, `nvidia/`, `citi/`, `oil/`, `salaries/`, `ai-bubble/`, `ai-correction/`, `dinar/` — one standalone page per article, each with its own URL
- `sitemap.xml` / `robots.txt` — for search engines

Every article is long-form, written in plain English, with figures verified from at least two independent sources. No investment advice — explainers only.

## Comments

Comments on each article are powered by [Giscus](https://giscus.app) and stored as GitHub Discussions in this repository — one discussion thread per article page. Anyone with a GitHub account can comment; the blog team moderates.
